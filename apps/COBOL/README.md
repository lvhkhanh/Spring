# COBOL Function Point Analysis for AS/400

This folder includes a simple COBOL program to calculate a function point count using the formula:

    FC = 4*I + 5*R + 10*F + 7*X + 4*Q

Where:
- `I` = Transaction inputs (online screens, batch input transactions)
- `R` = Reports generated by the application
- `F` = Application-specific files or DB2 tables maintained by the application
- `X` = Externally used files or external DB2 files shared with other programs
- `Q` = Query types or lookup/query operations

## Files

- `FPANALYSIS.cob` — COBOL program that accepts counts and computes the function count.
- `hello.cob` — existing sample program in the same folder.

## Best judgement for AS/400/CL/RPG/DB2 CRUD sample

For a minimal CRUD application on AS/400 with DB2 storage, a reasonable function point breakdown is:

- `I = 4` inputs: create, read, update, delete / search transaction screens
- `R = 2` reports: list and summary/report output
- `F = 1` application-specific file: the primary DB2 EMPLOYEE file
- `X = 1` externally used file: shared or external DB2 file accessed by the app
- `Q = 2` query types: read-by-id and list/query operations

That yields:

    FC = 4*4 + 5*2 + 10*1 + 7*1 + 4*2 = 51

## Usage

Compile and run in an AS/400 environment that supports COBOL:

    CRTCBLPGM PGM(LIB/FPANALYSIS) SRCFILE(LIB/QRPGLESRC)
    CALL PGM(LIB/FPANALYSIS)

Adjust the counts for your own application design and add additional screens, reports, or data files as needed.
